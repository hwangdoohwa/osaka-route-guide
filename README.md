# 오사카 길동무

간사이공항 제2터미널에서 신사이바시 병원까지, 일본을 처음 찾는 가족이 한 단계씩 따라가는 한국어 모바일 웹앱입니다.

공유 웹앱: https://hwangdoohwa.github.io/osaka-route-guide/

디자인 개편: [적용한 스킬·디자인 결정](DESIGN.md)

## 사용

`dist/`를 정적 웹 서버로 제공합니다. 로컬에서는 `python -m http.server 8766 --directory dist --bind 127.0.0.1` 후 `http://127.0.0.1:8766`을 엽니다. 설치·빌드 의존성이 없습니다.

- 6단계 현재 장소 → 다음 목적지 안내, 표지판 일본어·영어 병기
- 완료 표시·마지막 단계·선택 입력 방문시간을 브라우저에 저장
- 전체 경로, 사진 확대, 공식 근거, Google 지도, 직원에게 보여줄 일본어
- 한 번 접속 후 앱 문구와 동봉 사진 오프라인 사용 지원
- 외부 사진·지도·공식 사이트는 인터넷 필요

진행 단계는 사용자가 직접 표시합니다. GPS 추적이나 열차 실시간 조회 기능은 없습니다. 공유 시 다른 기기의 진행 상태나 입력한 시간이 전달되지 않습니다.

## 경로와 범위

제2터미널 → 무료 셔틀 → 에어로플라자 → 난카이 간사이공항역 NK32 → 난바 NK01 → 미도스지선 난바 M20(2번 승강장, 우메다 방면) → 신사이바시 M19 → 북쪽 개찰구·크리스타 나가호리 북8 출구 → 미나미센바 3-6-18 케즈빌딩 10층.

소요시간은 세관 통과 뒤를 기준으로 한 계획 범위입니다. 특정 여행일의 열차 연결을 보장하지 않습니다. 현장 전광판과 직원 지시를 우선하세요.

확인일: 2026-11-22. 안내 근거는 [자료·사진 출처](SOURCES.md)를 확인하세요.

## 제작 스킬

`skills/route-guide-webapp/`의 표시 이름은 **길안내 웹앱 만들기**입니다. 폴더를 `~/.codex/skills/route-guide-webapp`에 복사하면 사용할 수 있습니다. 호출 예:

> $route-guide-webapp 스킬로 간사이공항에서 신사이바시까지 가족용 길안내 웹앱을 만들어줘.

상세 제작 프롬프트: [production-prompt.md](skills/route-guide-webapp/references/production-prompt.md)
