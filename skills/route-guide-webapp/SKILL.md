# 길안내 웹앱 만들기

모바일에서 현재 위치, 다음 목적지, 찾아야 할 표지와 해야 할 행동을 바로 구별할 수 있는 웹앱을 만든다. [제작 프롬프트](references/production-prompt.md)를 해당 여행에 맞게 사용한다.

## 조사와 자료
- 사용자가 확정한 출발지·도착지·이동 수단을 유지한다. 이동 단계는 이용자가 실제로 확인할 수 있는 장소 기준으로 나눈다.
- 공식 공항·철도·병원 자료로 역 이름, 노선, 방향, 승강장, 출구를 확인한다. 승강장이 열차마다 달라지면 당일 전광판 확인을 명시한다.
- 일본어 블로그·안내자료에서 최근 실사를 찾고 촬영일·게시일·확인일을 구분한다. 게시가 최근이라는 이유만으로 사진도 최신이라고 쓰지 않는다.
- 원본 사진·공식 도면을 그대로 사용하고 사진 속 글씨와 구조를 이미지 생성으로 재구성하지 않는다. 방향 화살표를 추가할 때는 원본과 분리한 레이어로 표시한다.
- 자료마다 출처, 시점, 구간, 재배포 허용 근거를 기록한다. 허용 근거가 없는 사진은 공개 GitHub에 복제하지 않고 출처 링크로 제공한다. 현재와 다른 방향의 사진은 역방향 자료라고 명시하거나 사용하지 않는다.
- 확인되지 않은 출구문·차량·문 번호·정차 수를 추정으로 확정하지 않는다. 경로 선택이 명확한 경우에만 빠른 하차 위치를 제시한다.

## 구현
- 기본은 빌드 없는 HTML/CSS/JavaScript. 각 단계에서 현재 장소→다음 목적지, 한 번에 따라할 행동, 실제 표지 문구와 반대방향 경고를 보여준다.
- 단계 완료 버튼, 전체 경로, 사진 확대, 근거 보기, 주소 복사, 지도 열기, 직원에게 보여줄 일본어 문장을 제공한다.
- localStorage는 try/catch로 다루고 완료 상태와 마지막 단계를 재방문 후 복원한다. 저장 실패 시에도 안내는 동작한다. 가족 공유 URL은 각자 기기 진행 상태와 구분한다.
- GPS 자동 진행을 가장하지 않는다. 위치 권한 없이 안내를 볼 수 있고 실시간 길찾기는 외부 지도에서 연다.
- 예약 시각 등 개인 설정은 브라우저에만 저장한다. 공개 소스에 여행자의 이름·연락처·예약번호·건강정보를 넣지 않는다.
- 노선 색상뿐 아니라 문자·번호·아이콘을 함께 쓴다. 버튼은 터치하기 쉽게, 모바일 글씨는 크게, 확대화면은 닫기·Escape·키보드를 지원한다.

## 검증·공유
- 모바일/데스크톱 레이아웃, 다음/이전, 완료/되돌리기, 새로고침 복원, 사진실패 대체문구, 지도·출처 링크를 실제로 확인한다.
- 외부 사진·공식 도면은 파일 라이선스와 별도다. 배포 패키지에서 비밀값·인증자료·개인정보를 제외하고 사용한 자료의 저작권 고지를 유지한다.
- 사용자가 정한 게시·업로드 확인 규칙을 따른다. 승인 직전에 검수 가능한 결과물, 계정·저장소·공개 범위를 제시한다. 공유 링크는 실제 배포 성공 후에만 완료라고 보고한다.

## 초행길 연결 검증
- 표 구입/좌석 지정, 입장 개찰, 플랫폼 선택, 승차, 하차, 출장 개찰을 이동 순서대로 누락 없이 연결한다. 종이표·IC·온라인 교환형·QR 직접입장형을 구별한다.
- 가족의 성인·아동 운임 구분과 각자 사용할 표를 안내하고, 오류·지연·지각·통신 문제 시 행동을 넣는다.
- 지도 링크는 승차 구간에 도보 모드를 쓰지 않는다. 역 출구와 지하상가 출구 번호의 체계를 구별하고 방문 시설의 공식 상세 경로를 우선한다.
- 사진 원문의 목적지가 다른 경우 공통 이동 구간만 참고한다고 명시한다. 미확인 근접 사진이나 방향은 채우기 위해 추정하지 않는다.
