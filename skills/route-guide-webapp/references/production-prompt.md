# 길안내 웹앱 제작 프롬프트

출발지와 도착지 사이를 처음 방문하는 한국인 가족이 쉽게 따라갈 수 있는 모바일 웹앱으로 만들어줘. 최신 사진을 우선 조사하고 촬영일, 게시일, 확인일을 구분해 근거 목록을 먼저 작성해줘. 원본 이미지는 그대로 사용하고 AI로 실사와 도면을 다시 그리지 마. 재배포가 허용되지 않은 사진은 복제 대신 원문보기 링크를 제공해줘.

각 단계 화면에는 현재 위치→다음 목적지를 가장 크게 표시하고, 행동 2~4개, 찾아야 할 일본어·영어 표지, 반대 방향 경고, 도보·대기·승차시간의 구분을 넣어줘. 단계 완료/이전/다음 버튼과 전체 경로 탭, 원본사진 확대, 출처·확인시점, 주소복사, 구글 지도 연결, 직원에게 보여줄 일본어 문장을 제공해줘. 완료 상태와 현재 단계는 localStorage로 저장하고 저장이 막혀도 안내는 동작하게 해줘. 실시간 위치는 구글 지도로 연결하고 위치 기반 자동 진행처럼 보이게 하지 마.

모바일에서 큰 글씨와 넓은 버튼을 사용하고 데스크톱에서도 읽기 좋게 만들어줘. 사진이 없거나 못 불러오면 빈 화면 대신 확인된 설명과 원문 링크를 보여줘. 확대창의 닫기, Escape, 키보드 이동을 지원해줘. 새로고침 복원과 각 버튼을 실제 브라우저에서 테스트해줘.

## 이번 적용 경로: 간사이공항 → 신사이바시
1. 제2터미널 국제선 수하물·세관 완료 → 도착 로비 → 국제선 도착구 외부 정면의 무료 연락버스.
2. 무료 셔틀 → 에어로플라자1F 하차 → 2F → 연결통로 → 간사이공항역(NK32).
3. NANKAI 개찰구 → 1층1·2번 승강장 중 전광판이 지정한 곳 → 난바(NK01)행 라피트 또는 공항급행. JR3·4번과 구별. 난바 종점까지 승차, 라피트는 지정좌석.
4. 난카이 난바3층북개찰구 → 1층 → 지하1층 → Osaka Metro 미도스지선 남북개찰구. 캐리어 동선은 엘리베이터 표지를 함께 안내.
5. 미도스지선2번 승강장 우메다·신오사카·미노오카야노 방면 → 한 정거장 뒤 신사이바시(M19). 1번 덴노지·나카모즈 방면 금지. 8호차 계단/에스컬레이터,9호차 엘리베이터는 공식 도면 근거와 함께 참고로 제시.
6. 신사이바시 북개찰구→1번출구→구글 지도 도보→AND미용외과 신사이바시원(大阪市中央区南船場3-6-18 ケーズビル10F). 계단과 엘리베이터 지상출구의 차이를 명시.

개인 예약시간·진행상태는 브라우저에만 저장하고 건강정보와 예약번호는 수집하지 마. 공유용 소스·자료·스킬을 같은 저장소에 정리하고 배포는 계정·내용·공개범위 최종 확인 후 진행해줘.

## 이번 디자인 개선 기준
html-ppt의 neo-brutalism 강조와 번호 카드 구성을 모바일로 조정하고 svg-infographic의 process-flow 원칙으로 세로 경로 도해를 만든다. 지금 할 일은 큰 노랑 카드, 실제 표지판은 짙은 안내판, 혼동 주의는 빨간 경고 상자로 분리한다. 귀여운 여행 요소는 보조로만 사용한다. 본문 표지판 이름·방향·승강장 번호를 선택 강조하고 원본 실사 사진은 수정하지 않는다.
